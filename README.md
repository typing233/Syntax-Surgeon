# 🏥 文字手术模拟器 - 语言医生

一款将语文纠错练习包装成文字手术模拟器的沉浸式解谜游戏，让玩家在望闻问切修复病句残篇的过程中，重塑语言基本功。

## 🎮 游戏特色

### 沉浸式游戏体验
- **残卷病历展示**：屏幕中央展示带有语病的"病历文本"，让玩家化身语言医生
- **医生角色系统**：随机分配可爱的动物医生角色（啄木鸟、小马、猫头鹰、熊猫）
- **望闻问切机制**：玩家通过"望"（观察文本）、"闻"（医生提示）、"问"（点击诊断）、"切"（修改确认）来完成治疗

### 核心玩法
- **点击纠错**：直接点击文本中认为有错误的字词，弹出修改框
- **即时反馈**：
  - ✅ 正确：文字发出绿光并平滑修正
  - ❌ 错误：屏幕轻微震动并扣除文气值
- **文气值系统**：初始100点，错误会扣除，耗尽则游戏结束
- **得分系统**：每治愈一个病例获得1分

### 错误类型
- **错别字**：如"晴郎"→"晴朗"，"鼓厉"→"鼓励"
- **赘字**：多余的字，需要删除，如"很多的作业"中的"的"

## 🚀 快速开始

### 环境要求
- Python 3.7+
- pip 包管理器

### 安装步骤

1. **克隆项目**
```bash
cd Syntax-Surgeon
```

2. **创建虚拟环境（可选但推荐）**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate     # Windows
```

3. **安装依赖**
```bash
pip install -r requirements.txt
```

4. **启动服务**
```bash
python app.py
```

5. **访问游戏**

打开浏览器，访问：`http://localhost:9346`

## 🎯 游戏玩法说明

### 开始游戏
1. 页面加载后，自动分配一个医生角色和一道练习题
2. 屏幕上方显示"文气值"（生命值）和"治愈病例"（得分）

### 诊断病句
1. **观察文本**：仔细阅读"残卷病历"中的句子
2. **识别错误**：根据提示的错误类型（错别字/赘字）寻找问题
3. **点击诊断**：点击你认为有错误的字词
4. **弹出修改框**：
   - 错别字：输入正确的字，点击"确认修改"
   - 赘字：直接点击"确认删除"

### 得分规则
- ✅ 正确回答：+1分，文字发绿光特效
- ❌ 错误位置选择：-10文气值，屏幕震动
- ❌ 错误答案：-15文气值，屏幕震动
- 💀 文气值为0：游戏结束，可选择重新开始

### 继续挑战
- 完成一道题后，点击"下一个病例"按钮继续
- 医生会根据你的表现给出鼓励或提示

## 🎨 界面设计

### 视觉元素
- **残卷病历**：仿古纸张样式，虚线边框，营造古代医书氛围
- **医生卡片**：圆角设计，头像悬浮动画，友好对话气泡
- **状态条**：文气值进度条随数值变化颜色（绿→黄→红）
- **动画效果**：
  - 正确答案：绿光扩散动画
  - 错误答案：屏幕震动、文字抖动
  - 反馈弹窗：弹性弹出动画
  - 医生头像：上下浮动动画

### 响应式设计
- 支持桌面端和移动端
- 小屏幕自动调整布局和字体大小

## 🔧 扩展开发

### 添加新练习题
在 `app.py` 的 `exercise_data` 数组中添加新的题目对象：

```python
{
    "id": 9,
    "original_text": "你的新句子。",
    "error_type": "错别字",  # 或 "赘字"
    "errors": [
        {
            "position": 2,  # 错误字符的起始位置（从0开始）
            "original_char": "的",  # 原错误字符
            "correct_char": "地",  # 正确字符（赘字则为空字符串""）
            "explanation": "这里是语法说明"
        }
    ]
}
```

## 🐛 故障排除

### 常见问题

1. **Flask启动失败**
   - 检查Python版本：`python --version`
   - 重新安装依赖：`pip install -r requirements.txt`

2. **页面无法访问**
   - 确认端口9346未被占用
   - 检查防火墙设置
   - 尝试访问 `http://127.0.0.1:9346`

3. **静态资源加载失败**
   - 确认 `static` 目录结构正确
   - 清除浏览器缓存
